# Public page / Página pública

A single static file (`index.html`, English and Spanish, no build step). GSAP and the Outfit font come from public CDNs; nothing else is loaded and nothing is collected. Every number on it is measured in this repository and links to its report. / Un solo archivo estático (`index.html`, inglés y español, sin compilación). GSAP y la fuente Outfit vienen de CDNs públicos; no se carga ni se recoge nada más. Cada cifra está medida en este repositorio y enlaza a su informe.

Preview / Vista previa: open `site/index.html` in a browser.
Publish / Publicar: enable GitHub Pages with source "GitHub Actions" (Settings > Pages); `.github/workflows/pages.yml` deploys `site/` on every push that changes it. / activa GitHub Pages con origen «GitHub Actions»; el flujo despliega `site/` en cada push que lo cambie.
