Model

While a model is loaded it holds the NPU: other programs cannot use it until you unload.
Cloud: your question and this conversation leave your PC and go to the provider you configured. Your files are never sent.

Search engine

Index

Folders that may be read

One folder per line. Write ~ for your whole home, or e.g. ~/Documentos. Hidden folders (.ssh, .config…), keys, .env, passwords, .git, build folders and more are always skipped. After changing this, press “Index now”.

Web search

Only your question text is sent to the search provider. The server refuses to fetch anything that points to your local network.

Cloud assist (your own API key)

Optional, per message. Works with any OpenAI-compatible endpoint (NVIDIA NIM / Nemotron, OpenRouter, Ollama…) or Gemini. Keys are stored only in ~/.config/npu-lab/providers.json (readable by your user only) and are never shown again.
